# Contributing

Thanks for your interest in contributing to MCP-Bridge!

## Ways to Contribute

### Report a Bug
Open an issue with:
- A clear title and description
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

### Suggest an API
If we're missing an API that should be in the directory, open an issue with:
- API name and description
- Link to OpenAPI spec or documentation
- Category suggestion

### Improve Documentation
Docs are in this repo under `docs/`. Submit a PR with your improvements.

### Share Feedback
Contact us through the [website](https://mcpbridge.org/contact) or open a discussion.
